# Multivariate Analysis of Driver License Test Data

This project explores a real-world dataset from Kaggle on driver license test results using multivariate statistical techniques:

- **PCA**: Reduced dimensionality, capturing ~72% variance in 4 components
- **Factor Analysis**: Identified latent traits – practical skills & theoretical knowledge
- **Linear Discriminant Analysis (LDA)**: Classified candidates into Qualified vs Not Qualified
- **Canonical Correlation Analysis (CCA)**: Examined relationships between theoretical and practical skills (r ≈ 0.79)

### 🔧 Tools Used
- Python
- pandas, NumPy, matplotlib, seaborn
- scikit-learn
